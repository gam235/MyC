# 树状数组 Fenwick Tree

支持单点修改、前缀和查询，均为 O(log n)。

```cpp
struct BIT {
    int n;
    vector<long long> tr;

    BIT(int n) : n(n), tr(n + 1) {}

    void add(int x, long long v) {
        for (; x <= n; x += x & -x) tr[x] += v;
    }

    long long sum(int x) const {
        long long res = 0;
        for (; x > 0; x -= x & -x) res += tr[x];
        return res;
    }

    long long rangeSum(int l, int r) const {
        return sum(r) - sum(l - 1);
    }
};
```
